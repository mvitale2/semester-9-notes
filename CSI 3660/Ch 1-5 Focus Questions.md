**1.1 Who originally created Linux?**

Linus Torvalds created Linux. He created it after trying to develop another operating system called MINIX for UNIX. Another software developer, Richard Stallman, started creating GNU with the Free Software Foundation. Both Linux and GNU would be combined in order to merge their utilities. 

**2.1 Which common commands are used to navigate through shells?**

Common commands used to navigate inside a shell are "cd," "ls," and "pwd." cd Changes the current directory by specifying a relative or absolute directory. ls Lists the files present in the current directory. pwd Prints the current directory, which is incredibly useful in shells that don't show the current directory in the prompt. 

**2.2 How can you access on-screen help for each command?**

You can view instructions for most commands using the "man" command. man Does not print output to the command line; rather, it takes over the entire window to display text. Passing -h or --help into a command can display help text on the command line. 

**2.6 What is the difference between a login shell and a non-login shell?**

A login shell only runs after the user inputs their username and password. Non-login shells open without requiring login information. To run commands that require a password, the user will have to login upon attempting to execute the command.

**2.10 What is the difference between a hard link and a symbolic link?**

A hard link has the exact same inode as another file. A symbolic link acts as a pointer to another file; it has a different inode. 

**3.1 Which user account is automatically created when Linux is installed?**

The "root" account is automatically created upon the installation of Linux. 

**3.2 What is the purpose of the bootloader?**

A boot loader places the operating system into memory. The operating system is stored on a hard drive in the master boot record. This step comes after the BIOS does system checks. The most popular boot loader is GRUB.
