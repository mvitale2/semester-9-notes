Internet of Things is a network of physical devices that rely on the internet and cloud storage to transmit information. 
## Best practices for for securing IoT devices
- MFA
- Logs
- Firmware updates
- Encryption (TLS, SSL, HTTPS, MQTT)
- Network segmentation
- Endpoint detection and response (EDR)
## Best practices for IoT privacy
- Consent
- Transparency
- Data accuracy
- Data confidentiality
## References
- NIST Special publication 800-183

## [[Risk|Risks]]
- Weak authentication
- Data interception
- Malware and botnets
- Physical attacks
- Privacy breaches
- Device hijacking
### Countermeasures
- Strong Authentication and Authorization
	- Biometric authentication
	- Public key infrastructure
- Encryption
	- E2EE
- Firmware updates
- Network security
- Physical security
	- Reduce tampering
