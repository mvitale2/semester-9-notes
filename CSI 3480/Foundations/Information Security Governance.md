**Security governance** is the structure of the organization's goals. It consists of:
- Strategic planning
- Organizational Structure
- Roles and Responsibilities
- Enterprise Architecture
- [[Policy|Policies]] and Guidance
The CISO and ISM (Info Sec manager) are part of Security Governance. The ISM is more operational, while the CISO is on the enterprise level. 

**Security management** takes input from Governance and develops the overall [[Cybersecurity]] framework. Management selects controls and allocates resources. 

**Security implementation** takes input from management and implements the framework. Implementation takes care of jobs like maintenance, auditing, patching, and performance measurement. 

Each part of this governance process takes information from internal incident and global [[Vulnerabilities|vulnerability]] reports, standards and best practices, and user feedback. 

Important outcomes from security governance:
- Strategic alignment
	- Supporting organizational objectives aligned with business strategies
- [[Risk]] management
	- Mitigating [[Risk|risks]] and reducing or preventing impact on information resources
- Resource management
	- Align [[information security]] budgets with overall enterprise requirements
- Value delivery
	- Managing information security investments to achieve optimum value
- Performance measurement
	- Determining metrics to measure the performance of the [[information security]] [[policy]]

## Capital Planning

## Security Planning
A security plan is a document outlining the [[Controls]] that are already in place and the future [[Controls]] that can be implemented. 
[NIST SP800-18](https://nvlpubs.nist.gov/nistpubs/legacy/sp/nistspecialpublication800-18r1.pdf) recommends that each information system in an organization should have a separate document with these elements:
- Name
- Owner
- Authorizing individual
- Assignment of security responsibility
- Security categorization
- Operation status
- Type
- Description
- System environment
- Interconnections/information sharing
- Related [[Law|laws]] or [[Policy|policies]]
- Existing [[Controls]]
- Planned [[Controls]]
- Completion date
- Approval date

- Encryption

- Change control
- Virus
- Retention
- Firewall
- BYOD
- Wireless
- Incident response
- Physical access
- Security awareness
- Network security
- Cloud computing
### Monitoring policy
The CISO should designate a group or individual to monitor employees and ensure that the policy is being followed.
#### Acceptable Use Policy
A type of security policy targeted at all employees who have access to one or more organization assets.
