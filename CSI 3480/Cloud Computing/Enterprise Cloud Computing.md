Involves moving a substantial portion, or even, all IT resources of an organization to the cloud.
# Characteristics of Clouds
- On-demand self-service
- Broad network access
	- Shared hardware and software resources over the internet
- Resource pooling
	- Logically isolate the same physical resources
- Rapid elasticity
	- Expand and reduce resources according to specified service requirement
- Measure service
	- Automatically monitor usage statistics
# Service Models
## Software as a Service (SaaS)
The company handles all services.
## Platform as a Service (PaaS)
The company manages everything but the applications and data the user chooses to use on the platform. For example, Google Docs. 
## Infrastructure as a Service (IaaS)
The company provides the base (networking, servers, storage, etc.), while the user manages applications, OS, data, etc.

# Deployment Methods
## Public Cloud
Cloud infrastructure that is marketed to consumers and organizations. Consumers share the cloud's resources. Usually relatively cheap, but less secure than a private cloud. 
## Private Cloud
A cloud computing environment used only by a single organization. It can only be accessed by employees within that organization. Far more secure than public cloud, but costs more and has less scalability.
## Hybrid Cloud
Shared applications and data through a wide area network or broadband connection that can be managed as a single IT architecture. 
## Community Cloud
Infrastructure that is shared by several organizations and supports a specific community. For example, all organizations involved within health systems share similar IT [[Policy|policies]], so they decide to pool their cloud resources together.

### Cloud Consumer
The user of the cloud resources.
### Cloud Broker
Manages the addition of new services to the cloud. 
### Cloud Provider
Manages the cloud's resources.
### Cloud Auditor
Oversees the internal workings of the cloud.
### Cloud Carrier
Transports the provider's services to the consumer.
