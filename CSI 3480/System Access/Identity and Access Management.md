IAM consists of several discrete activities that follow the stages of a user's life cycle within and organization. 
# Deployment Approaches
There are three deployment approaches for IAM:
- Centralized
	- Concentrated in a single physical or virtual location (i.e. Active Directory).
- Decentralized
	- Local, regional, or business units make the decisions for all access choices, provisioning management, and technology.
- Federated
	- Each organization subscribes to a common set of [[policy|policies]] for management of users.

# Identification vs Authentication
- Identification is showing who you are.
- Authentication is proving who you are by doing something like providing a password.
# Single Sign-On (SSO)
- Access to multiple authentication boundaries.
- Beyond SSO, federated identity management provides a standardized means of representing attributes. 
# IAM Best Practices
- Train staff to spot phishing attacks
- Encrypt sensitive data
- Use Multifactor Authentication
- Implement least-privilege access controls
- Implement portals for accessing the web as SaaS applications
- Protect mobile and cloud applications
