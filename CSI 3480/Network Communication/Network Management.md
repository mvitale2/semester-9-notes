**ISO Management Functional Areas.**

- Fault management
	- Detecting, isolating, and correcting abnormal operation of the OSI environment.
	- A fault is an abnormal condition that causes a device or system component to fail. 
	- A fault should be tracked after it is fixed to ensure it does not occur again. 
- Accounting management
	- Inform users of costs incurred or resources consumed
	- Enable resource limits
	- Enable costs to be combined
- Configuration Management
	- Set parameters that control routine operation
	- Obtain announcements of significant changes in the condition of the system
	- Initialize and close down managed objects
- Performance Management
	- Monitor activities on the network
	- Make adjustments to improve network performance
	- Gather statistical information
- Security Management
	- Support the application of security policies
