## ICMP
The Internet Control Message Protocol is used to troubleshoot computers that are having network connectivity issues. 
### In-class Activity
Since ICMP is used by command line tools like ping and traceroute, attackers can use it to launch denial of service attacks by flooding devices with these requests. Additionally, attackers could use traceroute to perform reconnaissance on a network's topology to identify vulnerabilities.
