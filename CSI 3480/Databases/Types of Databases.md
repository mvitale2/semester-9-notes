Key components of a database are:
- **Data**: Raw information
- **Tables**: Data is organized into tables which consist of rows and columns
- **Schemas**: The structure or design of the database, which defines how data is organized and how relationships between data are handled.
- **Queries**: Commands that can be sent to the database by users.
- **Indexes**: Data structures that improve the speed of data retrieval operations on a database
